Install BELL PR

BELL PR runs on your own computer. Start it with one npm command or run the Docker image, then sign in through the link it prints.

npx bell-pr

Requirements

  • Platforms: macOS, Linux, or Windows through WSL2.
  • Node.js 22 or later for npm, or Docker instead.
  • Git 2.40 or later.
  • The GitHub CLI (gh), signed in with gh auth login. BELL PR uses it to publish Draft PRs and to find projects.
  • One AI coding CLI, installed and signed in: the OpenAI Codex CLI, or Claude Code with your Claude plan or Anthropic API key. Usage counts against your own account.

Start with npm

npx bell-pr

BELL PR starts on http://127.0.0.1:4311 and opens a sign-in link in your browser. That link works until BELL PR restarts, so keep it to yourself. Keep the terminal open while you work; Ctrl+C stops BELL PR.

To install the bell-pr command instead:

npm install -g bell-pr
bell-pr

Useful commands

  • bell-pr open opens a new sign-in link when you closed the tab or lost the link. Each of these links works once, within two minutes.
  • bell-pr doctor checks Git, the GitHub CLI and the AI coding CLIs, and says how to fix what is missing.
  • bell-pr start --port 4400 uses another port.
  • bell-pr start --data-dir ./bellpr-data keeps the data somewhere other than the default ~/.bellpr.
  • bell-pr license trial starts the 14-day Pro trial.

Run with Docker (beta)

Docker support is in beta. Under Docker's default security settings the agents cannot start their sandbox, so analysis, reviews and code changes stall. To let them work, add --security-opt seccomp=unconfined --security-opt apparmor=unconfined --security-opt systempaths=unconfined to docker run. These options relax the container's own confinement so that the agent sandbox can start; use them only on a machine you control.

docker run -d --name bell-pr \
  -p 127.0.0.1:4311:4311 \
  -v bellpr-data:/data \
  -v bellpr-home:/home/node \
  -e GH_TOKEN \
  -e BELLPR_PUBLIC_URL=http://localhost:4311 \
  IMAGE

Replace IMAGE with the published image name: [OWNER: Docker image name]

  • -p 127.0.0.1:4311:4311 publishes the port on this computer's loopback interface only, so nothing else on your network can reach BELL PR.
  • The bellpr-data volume keeps your repositories, runs and notes; bellpr-home keeps the sign-ins of the tools inside the container.
  • Get a sign-in link with docker exec bell-pr bell-pr open --print.
  • The image includes Git, the GitHub CLI and the Codex CLI. For the Codex CLI, add -e OPENAI_API_KEY. Set the Git identity for commits with -e GIT_AUTHOR_NAME, -e GIT_AUTHOR_EMAIL, -e GIT_COMMITTER_NAME and -e GIT_COMMITTER_EMAIL.
  • Claude Code is not preinstalled. To use it, run docker exec -it bell-pr npm install -g @anthropic-ai/claude-code and then docker exec -it bell-pr claude auth login.

Windows

Install WSL2 and a Linux distribution, then follow the npm steps inside it. BELL PR does not run on Windows outside WSL2.
