Install BELL PR

BELL PR is free, open-source software (Apache License 2.0) that runs on your own computer. Start it with one npm command or run the Docker image, then open the address it prints.

npx bell-pr

Requirements

  • Node.js 22 or later for npm, or Docker instead.
  • Git 2.40 or later, which moving a contribution onto the latest target branch needs.
  • The GitHub CLI (gh), signed in with gh auth login. BELL PR uses it to publish Draft PRs and to find projects.
  • One AI coding CLI, installed and signed in: the OpenAI Codex CLI, or Claude Code with your Claude plan or Anthropic API key. Usage counts against your own account.
  • On Linux, bubblewrap and socat (for example sudo apt-get install bubblewrap socat), so that Claude Code agents that change code run in the operating system's sandbox.

bell-pr doctor checks all of this and says how to fix what is missing.

Platforms

  • macOS and Linux: install with npm.
  • Windows: install WSL2 and a Linux distribution, then follow the npm steps inside it. BELL PR runs on Windows only through WSL2.
  • Docker (beta): an image you build from the source, with Git, the GitHub CLI and the Codex CLI.

Start with npm

npx bell-pr

BELL PR starts on http://127.0.0.1:4311, where only this computer can reach it, and opens it in your browser. Keep the terminal open while you work; Ctrl+C stops BELL PR.

To install the bell-pr command instead:

npm install -g bell-pr
bell-pr

Useful commands

  • bell-pr doctor checks Git, the GitHub CLI and the AI coding CLIs, and says how to fix what is missing.
  • bell-pr start --port 4400 uses another port.
  • bell-pr start --data-dir ./bellpr-data keeps the data somewhere other than the default ~/.bellpr.

Run with Docker (beta)

Docker support is in beta. Under Docker's default security settings the agents cannot start their sandbox, so analysis, reviews and code changes stall. To let them work, add --security-opt seccomp=unconfined --security-opt apparmor=unconfined --security-opt systempaths=unconfined to docker run. These options relax the container's own confinement so that the agent sandbox can start; use them only on a machine you control.

Build the image from a checkout of the source, then run it:

docker build -t bell-pr .
docker run -d --name bell-pr \
  -p 127.0.0.1:4311:4311 \
  -v bellpr-data:/data \
  -v bellpr-home:/home/node \
  -e GH_TOKEN \
  -e OPENAI_API_KEY \
  -e BELLPR_PUBLIC_URL=http://localhost:4311 \
  bell-pr
  • -p 127.0.0.1:4311:4311 publishes the port on this computer's loopback interface only, so nothing else on your network can reach BELL PR. Inside the container BELL PR listens on every interface, so never publish the port without 127.0.0.1:. BELL PR has no sign-in, so a port published beyond 127.0.0.1 gives anyone who can reach it full use of BELL PR.
  • The bellpr-data volume keeps your repositories, runs and notes; bellpr-home keeps the sign-ins of the tools inside the container.
  • Get the address again with docker exec bell-pr bell-pr open --print --print-token. --print-token includes the API token; do not share that address.
  • The image includes Git, the GitHub CLI and the Codex CLI. -e OPENAI_API_KEY passes your OpenAI key to the Codex CLI; you can sign in inside the container instead. Set the Git identity for commits with -e GIT_AUTHOR_NAME, -e GIT_AUTHOR_EMAIL, -e GIT_COMMITTER_NAME and -e GIT_COMMITTER_EMAIL.
  • Claude Code is not preinstalled. To use it, run docker exec -it bell-pr npm install -g @anthropic-ai/claude-code and then docker exec -it bell-pr claude auth login.

Next steps

Open the sample project to see a finished contribution, then import a repository you want to contribute to. Everything stays on your computer until you publish a Draft PR.
