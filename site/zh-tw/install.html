安裝 BELL PR

BELL PR 是免費開源軟體（Apache License 2.0），在你自己的電腦上執行。用一條 npm 指令啟動，或執行 Docker 映像，然後開啟它印出的位址。

npx bell-pr

需求

  • Node.js 22 以上以使用 npm，或改用 Docker。
  • Git 2.40 以上，將貢獻移到最新目標分支時需要。
  • GitHub CLI（gh），以 gh auth login 登入。BELL PR 用它發布 Draft PR 並尋找專案。
  • 一套 AI coding CLI，已安裝並登入：OpenAI Codex CLI，或搭配你的 Claude 方案或 Anthropic API 金鑰的 Claude Code。用量計入你自己的帳號。
  • 在 Linux 上需要 bubblewrap 與 socat（例如 sudo apt-get install bubblewrap socat），讓會修改程式碼的 Claude Code agents 能在作業系統沙箱中執行。

bell-pr doctor 會檢查以上項目，並說明如何補齊缺少的部分。

平台

  • macOS 與 Linux：用 npm 安裝。
  • Windows：安裝 WSL2 與 Linux 發行版，再在其中依 npm 步驟操作。BELL PR 在 Windows 上僅透過 WSL2 執行。
  • Docker（beta）：從原始碼建置的映像，內含 Git、GitHub CLI 與 Codex CLI。

用 npm 啟動

npx bell-pr

BELL PR 會在 http://127.0.0.1:4311 啟動（僅本機可連線），並在瀏覽器開啟。工作時請保持終端機開啟；Ctrl+C 可停止 BELL PR。

若要改為安裝 bell-pr 指令：

npm install -g bell-pr
bell-pr

常用指令

  • bell-pr doctor 檢查 Git、GitHub CLI 與 AI coding CLIs，並說明如何補齊缺少的部分。
  • bell-pr start --port 4400 使用其他埠號。
  • bell-pr start --data-dir ./bellpr-data 將資料放在預設 ~/.bellpr 以外的位置。

用 Docker 執行（beta）

Docker 支援目前為 beta。在 Docker 預設安全設定下，agents 無法啟動其沙箱，因此分析、審查與程式碼變更會卡住。若要讓它們運作，請在 docker run 加上 --security-opt seccomp=unconfined --security-opt apparmor=unconfined --security-opt systempaths=unconfined。這些選項會放寬容器本身的限制，好讓 agent 沙箱能啟動；請只在你能掌控的機器上使用。

從原始碼 checkout 建置映像後執行：

docker build -t bell-pr .
docker run -d --name bell-pr \
  -p 127.0.0.1:4311:4311 \
  -v bellpr-data:/data \
  -v bellpr-home:/home/node \
  -e GH_TOKEN \
  -e OPENAI_API_KEY \
  -e BELLPR_PUBLIC_URL=http://localhost:4311 \
  bell-pr
  • -p 127.0.0.1:4311:4311 只在本機的 loopback 介面上公開埠號，因此網路上的其他裝置無法連到 BELL PR。容器內 BELL PR 會監聽所有介面，所以絕不要在沒有 127.0.0.1: 的情況下公開埠號。對外公開時，僅剩 API token 保護完整存取。請保持埠號私有；遠端存取請使用搭配 BELLPR_PUBLIC_URL 的 tailscale serve，或 ssh -L。
  • bellpr-data volume 保存你的 repositories、執行紀錄與筆記；bellpr-home 保存容器內工具的登入狀態。
  • 可用 docker exec bell-pr bell-pr open --print --print-token 再次取得位址。--print-token 會包含 API token；請勿分享該位址。
  • 映像內含 Git、GitHub CLI 與 Codex CLI。-e OPENAI_API_KEY 會把你的 OpenAI 金鑰傳給 Codex CLI；也可以在容器內登入。可用 -e GIT_AUTHOR_NAME、-e GIT_AUTHOR_EMAIL、-e GIT_COMMITTER_NAME 與 -e GIT_COMMITTER_EMAIL 設定 commit 的 Git 身分。
  • Claude Code 未預先安裝。若要使用，請執行 docker exec -it bell-pr npm install -g @anthropic-ai/claude-code，接著 docker exec -it bell-pr claude auth login。

下一步

開啟範例專案查看一份完成的貢獻，再匯入你想貢獻的 repository。在你發布 Draft PR 之前，一切都留在你的電腦上。原始碼 repo 在 docs/security-model.md 說明 agents 在你電腦上可做什麼，在 docs/privacy-and-data.md 說明什麼會離開你的電腦。
