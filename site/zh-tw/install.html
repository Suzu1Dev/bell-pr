開始使用

一行指令，開啟你的工作台。

開始之前 ↗

npx

macOS · Linux

›_ 終端機
npx bell-pr

需要 Node.js 22 以上與 npm；不需全域安裝，直接啟動 BELL PR。

先登入 GitHub 與 AI 工具，工作時保持終端機開啟。

npm

macOS · Linux

›_ 終端機
npm install -g bell-pr

需要 Node.js 22 以上與 npm；安裝後即可使用 bell-pr 指令。

登入所需工具後，執行 bell-pr。

curl

macOS · Linux

›_ 終端機
curl -fsSL https://bell-pr.suzu.tw/install | sh -s -- --lang zh-TW

安裝到你的使用者目錄；需要時自動準備 Node.js 24。

完成後，使用腳本印出的啟動指令或 PATH 設定。

brew

macOS · Linux

›_ 終端機
brew tap suzu1dev/bell-pr https://github.com/Suzu1Dev/bell-pr && brew install suzu1dev/bell-pr/bell-pr

需要 Homebrew；會一併安裝 Node.js、Git 與 GitHub CLI。

登入所需工具後，執行 bell-pr。

bun

macOS · Linux

›_ 終端機
bun add --global bell-pr

需要 Bun 與 Node.js 22 以上。

登入所需工具後，執行 bell-pr。

ps1

Windows · WSL2

›_ PowerShell
& { Invoke-RestMethod 'https://bell-pr.suzu.tw/install.ps1' -OutFile install.ps1 -ErrorAction Stop powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Lang zh-TW }

在 WSL2 Ubuntu 內準備工具與 Codex CLI；若缺少 WSL，會列出設定步驟。

在 Ubuntu 裡完成登入，再啟動 BELL PR。Windows 設定步驟

mise

macOS · Linux

›_ 終端機
MISE_NPM_PACKAGE_MANAGER=npm mise use -g node@24 npm:bell-pr@1.0.0

安裝 Node.js 24，固定使用 BELL PR 1.0.0，這次安裝選用 npm。

用 mise exec -- bell-pr 啟動。

BELL PR 免費開源，不需建立 BELL PR 帳號。真實貢獻需要 Git、已登入的 GitHub CLI，以及 Codex CLI 或 Claude Code。

本頁目錄

開始之前 支援平台 登入所需工具 開啟工作台 Windows 與 WSL2 npm 與常用指令 Docker（beta） 下一步

需求

  • Node.js 22 以上。curl 腳本會在需要時準備 Node.js 24；Homebrew、mise 與 WSL 安裝腳本也會提供 Node.js。
  • Git 2.40 以上，將貢獻移到最新目標分支時需要。
  • GitHub CLI（gh），以 gh auth login 登入。BELL PR 用它發布 Draft PR 並尋找專案。
  • 一套 AI coding CLI，已安裝並登入：OpenAI Codex CLI，或搭配你的 Claude 方案或 Anthropic API 金鑰的 Claude Code。用量計入你自己的帳號。
  • 在 Linux 上需要 bubblewrap 與 socat（例如 sudo apt-get install bubblewrap socat），讓會修改程式碼的 Claude Code agents 能在作業系統沙箱中執行。

bell-pr doctor 會檢查以上項目，並說明如何補齊缺少的部分。

平台

  • macOS 與 Linux：可選 curl、Homebrew、Bun、mise 或 npm。
  • Windows：使用 ps1 腳本搭配 WSL2 Ubuntu 或 Debian。目前不支援原生 Windows，這套流程尚未在真實 Windows 主機驗證。查看下方 Windows 步驟。
  • Docker（beta）：從原始碼建置的映像，內含 Git、GitHub CLI 與 Codex CLI。

登入所需工具

用 git config --global user.name "Your Name" 與 git config --global user.email "you@example.com" 設定 Git 身分，請將範例值換成自己的名字與電子郵件。執行 gh auth login，再用 codex login 或 claude auth login 登入 AI 工具，最後用 bell-pr doctor 檢查環境；使用 npx 時則執行 npx bell-pr doctor。

開啟工作台

curl 腳本會印出啟動指令與 PATH 設定，請依照它操作，讓終端機找到已安裝的工具。使用 npx 時，再次執行 npx bell-pr。Homebrew 或 Bun 安裝後用 bell-pr；mise 則用 mise exec -- bell-pr。工作時保持終端機開啟；Ctrl+C 可停止 BELL PR。

尚未登入時，可以用 bell-pr start --force 試用範例專案。範例不呼叫 AI，也不傳送內容到 GitHub；真實 Agent 工作仍需要已登入的 AI 服務。

Windows 與 WSL2

  1. 若尚未安裝 WSL2，在系統管理員 PowerShell 執行： 
    wsl --install -d Ubuntu

    若系統要求，請重新啟動 Windows。開啟 Ubuntu，建立一般 Linux 使用者與密碼。用 wsl --list --verbose 確認版本為 2；必要時執行 wsl --set-version Ubuntu 2。

  2. 在一般 PowerShell 執行上方 ps1 指令。它會在 Ubuntu 中準備 Git、GitHub CLI、Node.js、BELL PR 與 Codex CLI，過程可能要求 Linux 的 sudo 密碼。腳本也支援既有的 Debian 發行版與 Claude Code，但不會代你登入。
  3. 用 wsl -d Ubuntu 進入 Ubuntu，在裡面設定 Git 身分，再於 Linux 終端機執行： 
    gh auth login
codex login
bell-pr doctor
bell-pr

    若選擇 Claude Code，改用 claude auth login。專案請放在 WSL 中，例如 ~/projects；Windows 版工具的登入狀態不會沿用到 WSL。

  4. 之後從 PowerShell 啟動只需： 
    wsl -d Ubuntu -- bash -lc '$HOME/.local/bin/bell-pr'

    若使用其他發行版，請替換 Ubuntu。瀏覽器沒有開啟時，在另一個 WSL 終端機執行 bell-pr open --print --print-token，再於 Windows 開啟印出的連結。連結包含存取憑證，請勿分享。

用 npm 啟動

npx bell-pr

BELL PR 會在 http://127.0.0.1:4311 啟動（僅本機可連線），並在瀏覽器開啟。工作時請保持終端機開啟；Ctrl+C 可停止 BELL PR。

若要改為安裝 bell-pr 指令：

npm install -g bell-pr
bell-pr

常用指令

  • bell-pr doctor 檢查 Git、GitHub CLI 與 AI coding CLIs，並說明如何補齊缺少的部分。
  • bell-pr start --port 4400 使用其他埠號。
  • bell-pr start --data-dir ./bellpr-data 將資料放在預設 ~/.bellpr 以外的位置。

用 Docker 執行（beta）

Docker 支援目前為 beta。在 Docker 預設安全設定下，agents 無法啟動其沙箱，因此分析、審查與程式碼變更會卡住。若要讓它們運作，請在 docker run 加上 --security-opt seccomp=unconfined --security-opt apparmor=unconfined --security-opt systempaths=unconfined。這些選項會放寬容器本身的限制，好讓 agent 沙箱能啟動；請只在你能掌控的機器上使用。

從原始碼 checkout 建置映像後執行：

docker build -t bell-pr .
docker run -d --name bell-pr \
  -p 127.0.0.1:4311:4311 \
  -v bellpr-data:/data \
  -v bellpr-home:/home/node \
  -e GH_TOKEN \
  -e OPENAI_API_KEY \
  -e BELLPR_PUBLIC_URL=http://localhost:4311 \
  bell-pr
  • -p 127.0.0.1:4311:4311 只在本機的 loopback 介面上公開埠號，因此網路上的其他裝置無法連到 BELL PR。容器內 BELL PR 會監聽所有介面，所以絕不要在沒有 127.0.0.1: 的情況下公開埠號。對外公開時，僅剩 API token 保護完整存取。請保持埠號私有；遠端存取請使用搭配 BELLPR_PUBLIC_URL 的 tailscale serve，或 ssh -L。
  • bellpr-data volume 保存你的 repositories、執行紀錄與筆記；bellpr-home 保存容器內工具的登入狀態。
  • 可用 docker exec bell-pr bell-pr open --print --print-token 再次取得位址。--print-token 會包含 API token；請勿分享該位址。
  • 映像內含 Git、GitHub CLI 與 Codex CLI。-e OPENAI_API_KEY 會把你的 OpenAI 金鑰傳給 Codex CLI；也可以在容器內登入。可用 -e GIT_AUTHOR_NAME、-e GIT_AUTHOR_EMAIL、-e GIT_COMMITTER_NAME 與 -e GIT_COMMITTER_EMAIL 設定 commit 的 Git 身分。
  • Claude Code 未預先安裝。若要使用，請執行 docker exec -it bell-pr npm install -g @anthropic-ai/claude-code，接著 docker exec -it bell-pr claude auth login。

下一步

開啟範例專案查看一份完成的貢獻，再匯入你想貢獻的 repository。BELL PR 只會在你核准後，才將變更發布到 GitHub；AI 任務會將相關程式碼與指令交給你選用的服務商。原始碼 repo 在 docs/security-model.md 說明 agents 在你電腦上可做什麼，在 docs/privacy-and-data.md 說明什麼會離開你的電腦。
