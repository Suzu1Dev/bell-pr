安裝指南 ↗

npx

macOS · Linux

›_ 終端機
npx bell-pr

需要 Node.js 22 以上與 npm；不需全域安裝，直接啟動 BELL PR。

先登入 GitHub 與 AI 工具，工作時保持終端機開啟。

npm

macOS · Linux

›_ 終端機
npm install -g bell-pr

需要 Node.js 22 以上與 npm；安裝後即可使用 bell-pr 指令。

登入所需工具後，執行 bell-pr。

curl

macOS · Linux

›_ 終端機
curl -fsSL https://bell-pr.suzu.tw/install | sh -s -- --lang zh-TW

安裝到你的使用者目錄；需要時自動準備 Node.js 24。

完成後，使用腳本印出的啟動指令或 PATH 設定。

brew

macOS · Linux

›_ 終端機
brew tap suzu1dev/bell-pr https://github.com/Suzu1Dev/bell-pr && brew install suzu1dev/bell-pr/bell-pr

需要 Homebrew；會一併安裝 Node.js、Git 與 GitHub CLI。

登入所需工具後，執行 bell-pr。

bun

macOS · Linux

›_ 終端機
bun add --global bell-pr

需要 Bun 與 Node.js 22 以上。

登入所需工具後，執行 bell-pr。

ps1

Windows · WSL2

›_ PowerShell
& { Invoke-RestMethod 'https://bell-pr.suzu.tw/install.ps1' -OutFile install.ps1 -ErrorAction Stop powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Lang zh-TW }

在 WSL2 Ubuntu 內準備工具與 Codex CLI；若缺少 WSL，會列出設定步驟。

在 Ubuntu 裡完成登入，再啟動 BELL PR。Windows 設定步驟

mise

macOS · Linux

›_ 終端機
MISE_NPM_PACKAGE_MANAGER=npm mise use -g node@24 npm:bell-pr@1.0.0

安裝 Node.js 24，固定使用 BELL PR 1.0.0，這次安裝選用 npm。

用 mise exec -- bell-pr 啟動。

BELL PR 免費開源，不需建立 BELL PR 帳號。真實貢獻需要 Git、已登入的 GitHub CLI，以及 Codex CLI 或 Claude Code。

運作方式

把理解，放在送出之前

Vibe coding 讓程式碼更容易產出，理解與審查卻仍需要時間。BELL PR 幫助你在送出前釐清設計、驗證結果、說明取捨，避免把尚未理解的變更交給維護者釐清。

  1. 先理解專案的脈絡

    BELL PR 會引用專案自己的貢獻規則、確認該專案接受你的 pull request，並顯示你選定的 issue 是否仍開啟、還有誰在處理。

  2. 一起討論，再開始開發

    與 Lead 討論計畫和取捨，再由你核准。接著 Teammates、Reviewer 與 Test analyst 使用你選擇的 AI coding CLI，在隔離的 git worktree 中工作。

  3. 說清楚變更，做出自己的判斷

    比較不同做法，先回答每個檔案的問題，再看解釋。接著用自己的話說明整項變更，再決定是否核准。

  4. 送出草稿，再從審查中學習

    專案檢查通過後，用自己的話發布 Draft PR；再把維護者的審查意見與你原先的預估對照，練習你漏掉的地方。

在真實貢獻中，磨練工程品味

追問設計、比較取捨，再從審查回饋中修正判斷。練習選擇適合專案的做法，並說清楚為什麼。

把每次貢獻，變成你的能力。理解變更、自我檢查，再練習漏掉的地方。

  • 說明裡有你自己要答的題

    每個變更的檔案都附上改了什麼、為什麼、範例、取捨與另一種做法。你要先回答問題才看得到答案，並選擇你會採取哪一種做法。

  • 核准前用自己的話解釋回去

    只送出你能解釋的內容：一輪簡短的閉卷檢查，包含你自己的摘要與答案，由你自評。預設開啟；關閉時每次執行都會清楚標示。

  • 練習你漏掉的地方

    你曾自信卻答錯的題，以及讓你意外的維護者留言，會在幾天後回到你的練習牌組。沒有連續紀錄，也沒有分數。

  • 會讀你紀錄的教練

    教練回顧會讀取你在單一專案的紀錄，點出該專案維護者最常提出的事項，並依你自己的貢獻建立練習。可將一項貢獻的完整學習紀錄匯出為 Markdown。

尊重每個專案的做法。從貢獻規則到審查回覆，讓每一步都有依據。

  • 引用專案自己的規則

    關於 AI 使用、揭露與「用自己的話寫說明」等規則，會從專案自己的檔案引用（含檔案與行號），並在你發布時再次核對。

  • 仍開啟、仍是你的

    開始前與發布前，BELL PR 都會確認 issue 仍開啟，並查找是否有其他人被指派、認領，或已有連結到該 issue 的 pull request。

  • 下一份 PR 之前先把迴圈關上

    每個專案的發布有節奏：先回應你已開啟的 pull request 上的審查意見，再在該專案開啟更多。

  • 跟進審查意見

    閱讀維護者的回饋，並與你的預估對照。接著可讓 agent 在後續一輪處理你選定的留言——你先用自己的話重述每一則；你審查該輪後，再以一個 commit 推送。

你熟悉的工具，一起工作。尋找方向、協作實作，由你選擇工具與投入程度。

  • 有依據的方向建議

    agent 會閱讀專案並建議貢獻方向，每一項都引用所依據的程式碼或文件，BELL PR 會核對每一段引用確實存在。隨時可再要五個，每個專案最多 30 個。

  • 找到下一個貢獻

    探索功能會在 GitHub 搜尋符合你興趣、語言與難度的專案與 issue，讀取其貢獻規則，並說明投入程度與第一步。

  • 依變更規模組成的團隊

    一位 Lead、兩到四位 teammates、一位 Reviewer 與一位 Test analyst；每位 teammate 各自在獨立的 git worktree。可同時處理多項貢獻，上限由你設定（預設 2，最多 8）。

  • 你的工具、你的投入

    選擇 Codex CLI 或 Claude Code、模型、推理力度（含最深層級）與效率模式。agents 的網路存取預設關閉，直到你自行開啟。

常見問題

執行 BELL PR 需要什麼？

macOS、Linux，或透過 WSL2 的 Windows；Node.js 22 以上（或 Docker）；Git；已登入的 GitHub CLI；以及一套已安裝並登入的 AI coding CLI：OpenAI Codex CLI 或 Claude Code。安裝指南有詳細說明。

它用的是誰的 AI 帳號？

你的。BELL PR 執行你已安裝並登入的 AI coding CLI：Codex CLI，或搭配你的 Claude 方案或 Anthropic API 金鑰的 Claude Code CLI。用量計入你自己的帳號。

它會自己開啟 pull request 嗎？

不會。只有在你審查過每個變更的檔案、用自己的話解釋變更（除非你關閉該檢查）並核准草稿之後，BELL PR 才會發布 Draft PR。發布前會再次確認專案接受你的 pull request，且 issue 仍屬於你。

我的程式碼會送到 BELL PR 嗎？

不會。沒有 BELL PR 雲端。你的程式碼會送到你所選 coding CLI 背後的 AI 供應商，以及 GitHub，受你自己的帳號與各服務條件約束。

要花多少錢？

不用。BELL PR 依 Apache License 2.0 免費開源，無需帳號。你只需向所選 AI coding CLI 的供應商，為自己的用量付費。

BELL PR 是開源的嗎？

是。以 Apache License 2.0 授權、由社群維護，並依現狀提供、不附保證。授權涵蓋程式碼；BELL PR 名稱與標誌為專案商標，原始碼 repo 中的 TRADEMARKS.md 說明使用方式。歡迎貢獻：CONTRIBUTING.md 說明作法。

Pull request 會說明有 AI 協助嗎？

只有在你選擇、或專案要求時。草稿結尾可有一行可編輯的文字，說明 AI coding agents 協助準備變更且你已審查。除非你開啟，或專案自己的規則要求揭露，否則該行預設關閉。若專案要求揭露，BELL PR 在說明寫入前不會發布。請遵守各專案對 AI 輔助貢獻的規則；原始碼 repo 中的 docs/contributing-responsibly.md 說明負責任使用的意義。

可以關閉理解檢查嗎？

可以，在「設定 → 學習」中，經確認後關閉（確認會說明變更內容）。每個檔案仍須審查，你仍須核准 pull request；所有專案規則、issue 與節奏檢查仍適用，且未做檢查就核准的執行會永久標示。

BELL PR 是 GitHub、OpenAI 或 Anthropic 做的嗎？

不是。BELL PR 是獨立產品。它搭配你自行安裝並登入的那些公司工具運作。
