# BELL PR documentation

- [Getting started](getting-started.md): install, sign in, and your first
  contribution from import to Draft PR, with the agent team or written by
  you in Learn by hand.
- [Configuration](configuration.md): commands, `BELLPR_*` variables and
  the settings in the app.
- [Troubleshooting](troubleshooting.md): every error code with its fix,
  why publishing was blocked, and what to do when you lost the sign-in
  link.
- [Contributing responsibly](contributing-responsibly.md): what
  maintainers ask of contributors who use AI tools, in their own words,
  how each BELL PR check maps to it, the numbers BELL PR uses and what it
  cannot see.
- [Licensing](licensing.md): Free and Pro, the trial, activating a key and
  how keys are checked.
- [Privacy and your data](privacy-and-data.md): what is stored, what
  leaves your computer and how to delete it.
- [Upgrading](upgrading.md): updates, backups and data from older
  versions.
- [FAQ](faq.md).
- [Self-hosting](self-hosting.md): running BELL PR as a service or behind
  an HTTPS reverse proxy.
- [Docker](docker.md) (beta).
- [Security model](security-model.md): what BELL PR trusts, how agents are
  confined, and the limits of each protection.
- [Development](development.md): building and checking BELL PR from its
  source.
